# Portfolio Cas de Waard

## Bekijken
Dubbelklik op `index.html`. De site opent in je browser.

## Foto's en video
Foto's staan in `images/`, de promovideo in `media/`. Een foto vervangen: zet een nieuw bestand met dezelfde naam in de map.

## Tekst aanpassen
Elke pagina is een eigen bestand (`wie-ben-ik.html`, `wat-kan-ik.html`, enzovoort). De tekst staat tussen `<p>` en `</p>`. Het menu en de footer staan in `assets/main.js`.

## Kleuren
Bovenaan `assets/style.css` staan alle kleuren en lettertypes.
